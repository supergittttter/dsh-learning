# DSH 学习与商业化实践

系统学习 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH），并在其基础上构建可商业化的 AI Agent 产品。

## 当前进度

- 第一个产品方向：**家庭理财 Agent**（可信赖的家庭财务管家）
- 第一个可运行插件：`ledger-bundle`（记账 `record_expense` + 月度洞察 `spending_report`）
